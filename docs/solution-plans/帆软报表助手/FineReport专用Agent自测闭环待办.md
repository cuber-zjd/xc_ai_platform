# FineReport 专用 Agent 自测闭环待办

## 背景

当前小驰主链路已经升级为高权限 FineReport 专用 Agent：可以完整读取 CPT、解析报表结构、查询数据库、解析 Excel/Word 附件、直接生成 XML patch 或整份 WorkBook，并通过版本系统写入、预览校验和回档兜底。后续继续补强浏览器 DOM 级验证、参考报表检索质量和多轮自修复深度。

## 待办方向

1. 已引入高权限 ReAct 任务循环：理解需求、读取上下文、调用工具、生成补丁或完整 WorkBook、写入版本、预览验证、失败后继续定位。
2. 已接入基础验证工具：XML 合法性、版本写入、FineReport 预览校验；后续补强参数选择后刷新、下拉候选 DOM 检查等浏览器级验证。
3. 已暴露参考报表检索工具能力；后续增强按控件、数据集、填报、脚本、样式等能力的真实检索和片段引用质量。
4. 已支持 XML 校验失败时模型自修复；后续把 FineReport 预览错误、浏览器 DOM 状态、CPT 差异和控制台错误进一步结构化为下一轮修复上下文。
5. 已增加真正的流式接口：后端提供小驰 SSE 输出，前端展示工具进度、局部回答、写入结果和预览结果。
6. 历史经验仍按需检索，不直接写入系统提示词；后续补充相似报表成功/失败样本召回。
7. 版本控制保留为核心兜底：每次写入 CPT 仍通过平台结构版本和文件版本归档，中高风险不再阻断 Agent 修改能力，永久删除和回档仍需用户明确确认。

## 验收标准

- 用户反馈“预览空白”“下拉没有数据”“参数没生效”等问题时，小驰能自动读取相关 CPT 片段和参考报表，自行生成修复补丁并完成预览验证。
- 用户无需理解 XML 或内部 JSON，只看到自然语言的修改范围、风险提示、确认按钮和验证结果。
- token 使用保持按需读取：默认先读索引和片段，信息不足时允许读取完整 CPT；完整历史会话和大量样例行仍需摘要或检索后进入上下文。
