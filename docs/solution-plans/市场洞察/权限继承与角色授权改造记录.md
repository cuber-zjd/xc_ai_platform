# 权限继承与角色授权改造记录

## 改造口径

- 企业档案和监测配置是权限配置的主入口，支持按用户、部门、Insight 专用角色、所属公司和全员授权。
- 情报中心的数据权限继承自正式情报自身授权、所属企业授权和所属监测配置授权。
- 授权弹窗不再要求用户手填对象 ID，改为搜索选择人员、部门、Insight 专用角色或所属公司。
- Insight 角色单独维护在 `insight_role` / `insight_role_member`，不复用平台通用 `sys_role`，避免市场洞察权限和主系统权限混用。

## 本次实现

- 监测配置列表按 `monitor_config` 权限规则过滤，拥有编辑授权的 Insight 角色/部门/用户可以维护对应配置。
- 系统设置新增“洞察角色”页，可维护角色、补齐默认角色并给角色批量添加成员。
- 正式情报增加 `monitor_config_id` 字段，新入库情报会记录来源监测配置；旧数据启动时按 `raw_payload.crawl_result_id` 回填。
- 情报列表、详情、首页统计等可见情报 ID 查询补充企业和监测配置继承过滤。
- 权限规则接口返回授权对象名称和编码，前端列表不再只展示 `#ID`。
- 监测配置详情页增加“权限”按钮，复用企业档案同一套授权弹窗。
