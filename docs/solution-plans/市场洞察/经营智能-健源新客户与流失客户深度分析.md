# 经营智能-健源新客户与流失客户深度分析

## 1. 分析口径

分析日期：2026-07-03。

核心事实源：

- 发货事实：`jy_delivery_data_view2`，数据范围 2021-01-02 至 2026-07-03，客户数 2210。
- 客户主数据：`jy_customer_base`。
- 客户年用量：`jy_latest_usage`。
- 流失补充：`jy_lost_customer_extend`，记录数 2617，最新期间 2026-06。
- 销售利润：`jy_sale_profit`。
- 当前应收：`jy_accounts_receivable`，当前记录 111 行，涉及 26 个客户。
- 客诉：`jy_customer_complaint`，当前样本较少，只作为弱信号。

产品范围沿用健源客户经营报表主口径：

- 果葡糖浆
- 麦芽糖浆
- 差异化糖浆

关键口径区分：

1. 报表 90/180 天口径是“当月跨过阈值的客户”，不是截至当前的全量沉默客户池。
2. 深度分析同时补充“截至 2026-07-03 的存量沉默池”：90-179 天沉默、180 天以上沉默。
3. 新客户按“客户-产品粒度首次发货”识别。一个客户如果首次购买多个产品，会在不同产品下分别成为新客户产品记录。

## 2. 结论摘要

1. 新客户开发的“数量”不差，但“吨数贡献”和“利润质量”偏弱。2026 年截至 7 月 3 日，三类产品新客户首月发货量占总发货量普遍低：果葡糖浆 0.86%，差异化糖浆 1.02%，只有麦芽糖浆达到 3.30%。这说明新客户更多是试单/小单，尚未转化为稳定经营增量。
2. 2026 年新客户里已经出现一批高首单量客户，但不少客户利润为负。果葡糖浆 Top 新客户中，颐海（漯河）食品、上海代田、PT. GRAHA KIMIA SENTOSA、HOA BINH FOOD 等客户首单后有量，但利润为负或吨利润为负；这类客户不能只按“开发成功”看，应纳入“培育期价格/毛利修复”。
3. 90 天潜在流失是有效预警窗口，不是噪声。2025-07 至 2026-03 的 90 天跨阈值客户，后续 90 天恢复发货率约 24.6%-43.9%，后续 180 天恢复率约 29.8%-51.2%。换句话说，约一半客户在跨过 90 天后仍没有恢复，90 天节点应触发销售动作。
4. 2026-06 当月跨阈值风险中，90 天潜在流失的年用量风险远高于 180 天流失。2026-06 的 90 天潜在客户 45 户，年用量约 73549 吨；180 天流失客户 36 户，年用量约 9275.6 吨。90 天阶段才是挽回价值最大的窗口。
5. 存量沉默池规模远大于月报清单。按截至 2026-07-03 的最后发货日看，180 天以上沉默池中仅果葡糖浆国内市场就有 727 个客户产品记录、年用量 425735 吨；国际市场果葡糖浆也有 69 个客户产品记录、年用量 182010 吨。月报只展示当月跨阈值客户，会漏掉大量历史沉默但仍可能有战略价值的客户。
6. 流失补充数据存在“结构化分类不足”。2026-06 `jy_lost_customer_extend` 共 81 行，`is_lost` 和 `lost_reason` 仅 28 行填写；`specific_lost_reason` 和 `follow_measures` 各 61 行填写。大量真实原因写在具体原因里，但没有归入标准原因分类，导致 AI 无法稳定做原因归因。
7. 应收叠加需要单独升级为经营风险。90-179 天沉默池中，差异化糖浆存在超期金额 21325533 元、最长超期 121 天的记录；这已经不是普通流失跟进，而是“流失 + 回款 + 风控”联动问题。

## 5. 原因与跟进质量

2026-06 流失补充表：

- 总行数：81。
- `is_lost` 填写：28。
- `lost_reason` 填写：28。
- `specific_lost_reason` 填写：61。
- `follow_measures` 填写：61。

主要问题：

1. 标准原因填写不足。很多记录 `lost_reason` 为空，但 `specific_lost_reason` 写了“受产能及价格影响”“使用周期长”“多账户合作”等有效信息。
2. “未填 + 具体原因已填”的记录应该由 AI 自动归类到标准原因，例如价格敏感、使用周期长、多账户合作、账期原因、认证问题、业务停用。
3. 17 条记录完全缺少原因和措施，应作为数据质量信号推给销售负责人。

建议标准原因体系：

- 价格敏感：切换低价竞品、到货价格低于我方报价。
- 供应/产能：产能、供货稳定性、交付周期影响。
- 客户业务变化：停产、业务转型、产品不再使用。
- 多账户/主体切换：同集团或同品牌换主体采购。
- 账期/信用：账期原因、回款风险。
- 认证/质量/测试：认证问题、测试未通过。
- 季节/周期：采购周期长、淡旺季。
- 小客户低频：用量小、询单频率低。

## 7. 行动建议

### 7.1 新客户

1. 建立“新客户二单转化”指标：首单后 30/60/90 天是否复购、90 天累计吨数、90 天吨利润。
2. 对果葡糖浆新客户分两类管理：高量客户看利润修复，低量客户看二单转化。
3. 国际果葡糖浆计划缺口最大，应单列“国际新客户计划达成”信号，而不是合并进总新客户数。
4. 差异化糖浆应按“技术应用/方案型客户”管理，重点复制成都耀厚贸易这类小体量高复购高利润客户。
5. 修正客户年用量维护异常。青岛啤酒麦芽糖浆 90 天发货 350.11 吨，但年用量维护为 10 吨，明显不匹配。

### 7.2 流失客户

1. 把 90 天潜在流失升级为主战场。2026-06 的 90 天潜在风险年用量 73549 吨，远大于 180 天流失的 9275.6 吨。
2. 建立“90 天挽回率”指标：跨过 90 天后，后续 90/180 天是否恢复发货，并按业务员、产品、市场追踪。
3. 把存量沉默池分层：
   - 90-179 天：销售本月行动清单。
   - 180 天以上且近 365 天有销量：专项挽回池。
   - 180 天以上且多年无销量：历史客户池，只做周期复盘，不占用一线跟进资源。
4. 对多账户合作客户做主体合并，避免把“主体切换”误判为真实流失。
5. 对价格敏感客户沉淀竞品价格字段。当前具体原因里已出现“到货价格 2700/2800 元/吨”等信息，应该结构化存储。
6. 对应收叠加客户建立红色信号，不只推给销售，也推给财务/信用管理。

## 8. 建议沉淀为经营智能能力

第一批不要再做单纯看板，应做“客户生命周期分析 Agent”：

1. 新客户质量评分：
   - 首单量
   - 90 天复购
   - 90 天累计量
   - 吨利润
   - 年用量匹配度
   - 计划达成度

2. 流失风险评分：
   - 沉默天数
   - 年用量
   - 近 365 天销量
   - 去年销量/利润
   - 是否价格敏感
   - 是否多账户切换
   - 是否应收超期
   - 是否缺少原因和措施

3. 销售动作生成：
   - 高价值可挽回客户：输出客户、产品、业务员、最后发货、年用量、原因、建议动作。
   - 低利润新客户：输出报价/成本复核清单。
   - 资料缺口客户：输出需要补原因、补措施、补年用量的清单。

4. 经营问答样例：
   - “本月哪些 90 天客户最值得挽回？”
   - “新客户里哪些有量但亏损？”
   - “哪些客户不是流失，而是主体切换？”
   - “哪些流失客户叠加应收风险？”
   - “哪个业务员的 90 天客户恢复率最低？”

## 9. 数据 caveat

1. `jy_lost_customer_extend` 是按客户和期间记录，不天然按产品唯一；与客户-产品粒度联动时可能出现多产品客户的归因复用。
2. `sale_market` 在发货表中是 `10/20` 编码，新客户计划表中是“国内市场/国际市场”，分析中已临时映射，但后续应沉淀为维表。
3. `jy_new_customer_profit` 当前未能与本次产品市场计划口径稳定对齐，利润更多来自 `jy_sale_profit`。
4. 客诉数据样本很少，不建议作为主归因。
5. 年用量维护存在明显异常，应加入数据质量校验，否则会影响客户优先级。
