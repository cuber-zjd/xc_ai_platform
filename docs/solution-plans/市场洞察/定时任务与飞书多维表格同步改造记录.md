# 定时任务与飞书多维表格同步改造记录

## 1. 改造目标

- 给管理员提供统一的定时任务运行面板，集中查看启停状态、下次执行时间和每轮运行结果。
- 每轮任务记录监测对象、定时报告、飞书同步、失败原因、模型调用次数和 Token 消耗。
- 在情报中心支持按已选情报或发布时间同步飞书多维表格，并允许用户选择同步字段。
- 同步过程自动处理重复数据和多维表格字段、单选、多选选项变化，减少人工维护表结构。

## 2. 页面与权限

- 管理员入口：`/insight/schedules`。侧栏入口和路由均受管理员权限控制，后端调度状态、启停、立即执行和日志接口再次校验管理员身份。
- 情报中心正式情报工具栏增加“同步飞书”。普通用户只会同步自己有权查看的情报；管理员可同步权限范围内的全部正式情报。
- 页面根容器保持固定工作台结构，运行日志、字段列表和详情分别在组件内部滚动。

## 3. 定时任务日志

每轮 `scheduler_tick` 任务写入以下信息：

- 触发方式、开始/结束时间、状态和耗时。
- 检查、到期、成功和失败的监测对象数量。
- 定时报告成功、失败数量。
- 飞书新增、更新、跳过、失败数量。
- LLM 输入 Token、输出 Token、总 Token、调用次数和分模型用量。
- 失败原因及本轮结构化输出。

Token 统计通过请求上下文收集器汇总本轮任务内的模型调用。改造前的历史任务没有模型用量数据，页面按 0 展示并明确提示，不反向估算。

## 4. 飞书同步规则

1. 同步范围支持“已选情报”和“按发布时间”。时间范围以文章发布时间为准，不使用系统入库时间替代。
2. `情报ID` 是多维表格的幂等键。已存在时更新原记录，不存在时新增，重复点击不会产生重复行。
3. 用户可选择标题、摘要、正文、企业/监测对象、所属公司、分类、标签、重要性、选中理由、业务启示、机会风险、来源和链接等字段。“企业/监测对象”表示被监测客户、竞对或主题；“所属公司”表示该情报服务的内部产业公司，两者不得混用。
4. 企业监测情报从企业档案的 `sys_company_id` 继承所属公司；行业、政策、舆情等主题监测从监测配置 `config_json.business_sys_company_ids` 读取，可同时归属多家内部公司。飞书“所属公司”使用多选字段，缺失字段、字段类型和选项均由同步服务维护。
5. 表格中已存在但类型不兼容的字段，仅在可安全转换为文本时自动调整；其他异常写入同步任务失败明细，不静默吞掉。
6. 每次同步写入 `feishu_bitable_sync` 任务，保留新增、更新、跳过、失败、元数据调整和错误信息。

## 5. 自动同步

- 手动同步只要求飞书应用、多维表格 app token 和 table id 配置完整。
- `INSIGHT_FEISHU_SYNC_ENABLED=true` 时，调度器每轮采集及报告完成后同步最近两天正式情报。
- 自动同步复用同一套幂等、权限、字段选择和元数据维护服务，不另写一次性脚本。

- 实测自动补充了分类、风险/机会和来源渠道相关元数据，没有要求人工进入多维表格逐项维护。
